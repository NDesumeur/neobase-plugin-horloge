# Horloge mondiale

L'heure dans plusieurs villes du monde, dans NeoBase, avec un décalage pour savoir quelle heure il
sera ailleurs à un moment donné.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Horloge mondiale → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
